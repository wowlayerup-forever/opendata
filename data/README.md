# data/

JSON Lines per layer and table. The schema for `data/<layer>/<table>.jsonl` is `schemas/<layer>/<table>.schema.json`. `data/api/` is split by build: `data/api/<build>/functions.jsonl`.

`client/` is generated by `tools/extract_client.py` (DB2) and `tools/import_cache.py` (client cache); `api/` by `tools/import_api.py`; `world/` by `tools/reconcile.py` from players' observation batches. Do not hand-edit any of them; fix the tool. `derived/` is written by people and agents, attributed. See CONVENTIONS.md and AGENTS.md.
